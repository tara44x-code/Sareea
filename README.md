# SDM+: مدير التحميل لأندرويد

مدير تحميل لأندرويد 10 وما فوق. يحمّل الملفات المباشرة، والفيديو والصوت من المواقع، والتورنت.

## التنصيب
روح لقسم **Releases** بالمستودع، ونزّل **SDM-plus-arm64.apk** من آخر نسخة. هذا الملف يشتغل على أغلب الموبايلات. التحديثات الجاية تنصّب فوگ القديمة مباشرة، لأن كل النسخ موقّعة بنفس المفتاح.

## المميزات
**الملفات المباشرة**
- يقسّم الملف الواحد لحد 32 اتصال حتى يسرّع التحميل
- إيقاف واستئناف، وإعادة محاولة تلقائية إذا انقطع النت

**الفيديو والصوت** (عن طريق yt-dlp)
- يوتيوب، تيك توك، انستغرام، فيسبوك، تويتر/X، وأكثر من 1000 موقع ثاني
- تختار الجودة (4K، 1080p، 720p…) أو تحمّل صوت بس بصيغة M4A أو MP3
- محرك الفيديو يتحدث وحده مرة باليوم، وتگدر تحدّثه يدوياً من الإعدادات

**التورنت** (عن طريق libtorrent)
- روابط magnet وملفات .torrent
- تختار الملفات اللي تريدها من داخل التورنت
- يبين عدد المصادر والوقت المتبقي
- خيار للتحميل على الواي فاي بس، والمشاركة (seeding) توقف تلقائياً من يخلص التحميل

**التقاط التحميلات**
- **متصفح داخلي:** أي تحميل تبديه بأي موقع ينلگط ويروح لـ SDM+، وينتقل وياه تسجيل الدخول (الكوكيز)
- زر **«حمّل الفيديو»** يطلع وحده من تفتح موقع فيديو
- **«التقط كل ملفات الصفحة»:** يجمع كل الملفات اللي بالصفحة وتختار منها
- **المشاركة:** تشارك أي رابط من أي تطبيق إلى SDM+
- **«فتح بواسطة»:** روابط apk وzip وmp4 والتورنت تنفتح بالتطبيق
- **تحديد النص:** تحدد رابط بأي مكان وتختار «تحميل بـ SDM+»
- **الحافظة:** إذا نسخت رابط، التطبيق يسألك تريد تحمّله

**غيرها**
- قائمة انتظار، حد للسرعة، والتحميل على الواي فاي بس
- ترتيب تلقائي: الملفات تنحفظ بمجلد `Download/SDM/` وتنقسم لمجلدات حسب النوع
- تصدير كل الروابط، واستئناف الكل أو إيقاف الكل بضغطة
- إشعارات تبين التقدم، وبالإشعار زر «إيقاف الكل»
- الواجهة بالعربي والإنكليزي، وبيها وضع ليلي

## البناء
كل ما يترفع كود جديد على `main`، GitHub Actions يبني التطبيق وينشر نسخة جديدة بقسم Releases. وإذا تريد تبنيه بنفسك، افتح المشروع بـ Android Studio واختار **Build ← Build APK(s)**.

## ملاحظات
- **مفتاح التوقيع** محفوظ بأسرار GitHub (Settings ← Secrets and variables ← Actions) باسمين: `SDM_KEYSTORE_B64` و `SDM_KEYSTORE_PASSWORD`. إذا انحذفن، البناء يكمل بمفتاح مؤقت، بس التحديثات وقتها ما تنصّب فوگ النسخة القديمة.
- **الترخيص:** التطبيق يستخدم youtubedl-android المرخّصة بـ GPL-3.0، فإذا توزّع التطبيق لازم تنشر كوده بنفس الترخيص.
- **المسؤولية:** إنت مسؤول تحترم حقوق المحتوى اللي تحمّله وشروط المواقع اللي تحمّل منها.
