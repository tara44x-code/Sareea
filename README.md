# سريع (Sareea): مدير تحميل لأندرويد

تطبيق تحميل سريع لأندرويد 10 وما فوق، مكتوب بلغة Kotlin وواجهة Jetpack Compose.

## المميزات بهذي النسخة
- **تحميل سريع بأكثر من اتصال:** يقسّم الملف إلى 32 جزء كحد أقصى، وكل جزء يتحمّل باتصال منفصل.
- **إيقاف واستئناف:** يكمّل من نفس المكان حتى لو سدّيت التطبيق أو طفيت الجهاز.
- **إعادة محاولة تلقائية:** إذا انقطع النت بنص التحميل، يرجع يحاول وحده.
- **قائمة انتظار:** تحدد كم ملف يتحمّل بنفس الوقت (من 1 إلى 5)، والباقي ينتظر دوره.
- **حد للسرعة:** تحدد سرعة قصوى للتحميل كله.
- **ترتيب تلقائي:** الملفات تنحفظ بمجلد `Download/Sareea/` وتنقسم لمجلدات حسب النوع (فيديو، موسيقى، مستندات...).
- **إضافة روابط هواية مرة وحدة:** تلصقها بمربع الإضافة، وكل رابط بسطر.
- **مشاركة من المتصفح:** تضغط مشاركة على أي رابط وتختار «سريع». هذا بديل إضافة المتصفح اللي بنسخة الويندوز.
- **مراقبة الحافظة:** إذا نسخت رابط، التطبيق يسألك إذا تريد تحمّله.
- **إشعارات:** إشعار يبين التقدم وبيه زر «إيقاف الكل»، وإشعار ثاني من يخلص التحميل تضغط عليه ويفتح الملف.
- **الواجهة بالعربي والإنكليزي** حسب لغة جهازك، وتدعم الوضع الليلي.

## شلون تطلّع ملف APK
1. نزّل [Android Studio](https://developer.android.com/studio) ونصّبه (مجاني).
2. فك ضغط هذا المجلد، وبعدين من Android Studio اختار **File ← Open** وأشّر على مجلد `Sareea`.
3. انطي Android Studio وقت يكمّل التحميل والمزامنة (Gradle Sync). أول مرة ممكن ياخذ كم دقيقة. إذا طلع اقتراح تحديث لـ Gradle أو AGP، تگدر توافق عليه.
4. من القائمة اختار **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**.
5. الملف يطلع هنا: `app/build/outputs/apk/debug/app-debug.apk`. انقله للموبايل ونصّبه، ولازم تفعّل خيار «السماح بالتثبيت من مصادر غير معروفة».

أو تگدر توصل الموبايل بالكيبل، تفعّل «تصحيح USB» (USB debugging)، وتضغط زر ▶ بـ Android Studio حتى ينصّبه مباشرة.

> نسخة الإصدار (release) هسه موقّعة بمفتاح التجربة حتى تنصّبها بسهولة. قبل لا تنشر التطبيق على Google Play لازم تسوي مفتاح توقيع خاص بيك من **Build ← Generate Signed Bundle / APK**.

## هيكل الكود
```
app/src/main/java/com/sareea/downloader/
├── App.kt                    تشغيل التطبيق وربط الأجزاء
├── engine/DownloadEngine.kt  محرك التحميل: الأجزاء، الاتصالات، الاستئناف، قائمة الانتظار
├── engine/SpeedLimiter.kt    حد السرعة
├── engine/FileUtils.kt       أسماء الملفات، أنواعها، والحفظ بالتنزيلات
├── data/Store.kt             حفظ قائمة التحميلات
├── data/Settings.kt          الإعدادات
├── service/                  خدمة تخلي التحميل مستمر بالخلفية، والإشعارات
└── ui/                       الشاشات والثيم
```
